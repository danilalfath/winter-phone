# ❄️ Winter's iPhone 16 Pro Simulator

iOS 18 Simulator dengan tema Winter aespa.

## 🌟 Fitur

- 📱 iPhone 16 Pro dengan Dynamic Island
- 🔒 Lock Screen dengan passcode (0101)
- 🏠 Home Screen dengan app icons iOS asli
- 🎛️ Control Center lengkap
- 📸 Photos App dengan album
- 💬 iMessage dengan bubble chat
- 🎵 Apple Music player
- 📝 Notes App
- 📞 Phone & FaceTime
- ⚙️ Settings CMS

## 🚀 Live Demo

https://USERNAME.github.io/winter-iphone-simulator/

## 📖 Cara Menggunakan

1. Klik tombol power untuk lock/unlock
2. Masukkan passcode: **0101**
3. Explore semua fitur iOS 18!

## 🎨 Kustomisasi

- Ganti wallpaper di Settings > Wallpaper
- Tambah foto di Photos app
- Buat chat baru di Messages
- Tambah lagu di Music app
